## 三、为什么这条现在可以支撑 `error`

按 `rules/evidence/authority-class-audit.md` 第二节确立的判据：

1. **效力来源**：国卫办医发〔2016〕24 号是**国家卫生计生委办公厅以文号印发的规范性文件**，
   对医疗机构设定住院病案首页填写要求 ⇒ **B 类，可以 `error`**。
2. **B 类的硬前提**：「**所引条款的文本必须已逐字取得**」——
   **本次已满足**（第二节）。这正是 2026-10-07 降级时唯一缺失的条件。
3. ⇒ **`MR-001` 的 `kind: direct` + `severity: error` 成立**。

⚠️ **本条 `kind` 此前已是 `direct`**（见 `clause-verification-homepage-spec.md` 第三节末尾：
"该引文的措辞与 note 描述的表头注释用途一致，**没有任何理由怀疑其不实**"）——
缺的只是**逐字核对**这一步，而不是效力来源的判定。

## 六、复现方法

```sh
# 下载汇编件（HTTP 200，application/pdf，328 页，有文字层）
curl -sI http://hncis.hnwsjk.cn/bingan/upload/files/2024/6/3813adce8fc5b87f.pdf
curl -s -o hn-24hao.pdf http://hncis.hnwsjk.cn/bingan/upload/files/2024/6/3813adce8fc5b87f.pdf

# 提取文字层并定位注释（需 PyMuPDF；实测该 PDF 有文字层，未使用任何 OCR）
python -c "import pymupdf,re;d=pymupdf.open('hn-24hao.pdf');t=''.join(p.get_text() for p in d);print('必填栏不能为空项' in re.sub(r'\s+','',t))"
# 预期输出：True（位于 PDF 第 113 页）
```

⚠️ **未使用 OCR**：本 PDF **自带文字层**（205,847 字符可提取），提取结果即文本本身，
不存在"把识别不确定性伪装成引文确定性"的问题。这是本条与 `dsh-site-log-check` 那份
**无文字层扫描件**的关键区别。
